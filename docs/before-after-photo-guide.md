# Before / After 撮影ガイド

施工前後の変化を正しく伝えるため、施工前に「Afterでも同じ構図で撮る写真」を決めます。写真の比較では、色や仕上がりだけでなく、撮影位置・距離・明るさの違いも印象を大きく変えます。

## 撮影前の準備

- 養生前にAfter用の撮影位置を決め、足元をマーキングするか、門・電柱・境界ブロックなどを基準に位置をメモする。
- スマートフォンは同じレンズ（標準/広角を混ぜない）、同じ縦横向き、同じ高さで撮る。
- 被写体までの距離と、建物を画面内に入れる範囲を合わせる。
- 車・自転車・ゴミ箱・洗濯物などの移動物は、可能な限り写さない。写る場合はBeforeとAfterで位置をそろえる。
- 曇天・晴天、順光・逆光などの光条件をできるだけ近づける。時刻と天候もメモする。

## 定点リスト

各カットを施工前と施工後で必ず1組ずつ撮影します。

1. 正面全景
2. 東面・西面・南面・北面
3. 見上げ（屋根・破風・軒天が分かる角度）
4. 付帯部の寄り（雨樋、破風、軒天、シャッター、雨戸など）
5. 劣化箇所の寄り（ひび割れ、目地、コーキング、雨だれ、チョーキング）

## 撮影時の確認

- Beforeを見返し、屋根線・窓・換気フードなどの位置がAfterでも同じ位置に入っているか確認する。
- 全景と一部アップを同じペアにしない。比較として掲載するのは、同じ面・同じ距離・近い画角の写真だけにする。
- Beforeがない施工後写真は「施工後の全景」「施工後のディテール」として単独掲載する。

## ファイル名

既存の命名規則に合わせ、`[地域]-[案件]-before-[場所].jpg` と `...-after-[場所].jpg` を対で付けます。

例:

```text
okegawa-sakata-before-front.jpg
okegawa-sakata-after-front.jpg
okegawa-sakata-before-lookup.jpg
okegawa-sakata-after-lookup.jpg
```

単独の施工後写真は、対応するBefore名を作らず、用途が分かる名前にします。

```text
okegawa-sakata-after-shutter.jpg
okegawa-kamogawa-after-wide.jpg
```
