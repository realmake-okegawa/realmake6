# Before / After 写真監査（2026-08-14）

判定基準は次の3段階です。

- **成立**: 同じ面・同じ主題が確認でき、仕上がりの差を無理なく比較できる。
- **弱い**: 主題は同じだが、立ち位置・距離・光・画角に差がある。
- **成立していない**: 別の面や別の主題で、Before/Afterとして並べると誤解を招く。

| ペア | 判定 | 確認結果 | 表示方針 |

| 隣家との通路 | 弱い | 同じ通路・同じ付帯部を写しているが、Afterは縦長で距離が近い。 | Before/Afterを維持。元比率のまま表示し、トリミングを解消 |

| 建物角部 / シャッターまわり | 成立していない | 対応するBeforeがない。 | 「施工後のディテール」として単独掲載へ変更 |

## 比率とトリミングの確認

- 坂田の通路・見上げは、Beforeが **3:4**、Afterが **9:16**。従来の3:4固定・`object-fit: cover`では、Afterの上下が切れていた。
- 鴨川はBeforeが **3:4**、Afterが **4:3**。ページ側でAfterに4:3指定があり、画像自体のトリミングは発生していない。ただし、ペアごとの表示比率はそろわない。
- 川田谷は全ペアが **3:4** で、意図しないトリミングはない。

今回、坂田の縦長Afterはペア全体を `4:3` / `3:4` の列幅にして元比率のまま表示するよう変更した。撮影し直しが必要なのは、比較の精度を上げたい坂田の正面・通路・見上げ、鴨川の正面・角部である。鴨川の西面と全景は、再撮影する場合も別々の単独カットとして扱う。
